# claude-tuner

> **你的 Claude 桌面端，你自己做主。**
> 
> 把 Claude 的控制权真正交还给用户。自由接入第三方模型与官方中转，按需调优工具与上下文，前缀稳定防缓存击穿。

```bash
curl -fsSL https://raw.githubusercontent.com/ls-open/claude-tuner/main/install.sh | bash
```

装完浏览器自动弹出配置台，填上你的 API Key 就能用 —— 接口地址、模型映射、环境变量一键搞定，无需繁琐折腾。

![配置页](assets/1-connect.png)

> ⚠️ **写在前面：适用场景与协议要求**
> - **✅ 适用对象**：通过 **API Key（Claude 桌面端 3P / 开发者接入模式）** 使用的用户。支持 Anthropic 官方 API Key、第三方兼容模型（如 DeepSeek）、各大官方中转站或自建反向代理。
> - **🚫 不适用对象**：在 Claude 桌面端直接使用**官方网页账号（Pro / Team 邮箱直接登录）**的场景。因官方网页登录通道为闭源闭环，无法自定义接入点，本项目不涉及且不支持该模式。
> - **⚡️ 协议要求**：上游接口必须原生支持 **Anthropic Messages 协议**（如 DeepSeek 填 `https://api.deepseek.com/anthropic`，或各大兼容中转端点）。本项目专注于模型调控与优化，**不做 OpenAI 格式到 Anthropic 格式的跨协议转译**。
> - **🍎 系统环境**：当前版本专为 **macOS** 优化打造（深度适配 macOS 进程锁与文件配置路径）。

## 💥 你是不是也被这些痛点折磨过？

如果你在日常使用 Claude 桌面端接入 API 或中转站，你大概率踩过这几个“暗坑”：

### 1. 💸 钱包刺客：明明只写了两行代码，首轮怎么就扣了上万甚至数万 Tokens？
- **背后真相**：Claude 官方客户端在完全体状态下（包含应用内浏览器工具、定时任务 Schedule、界面遥控、各种集成插件），会为**每一个可用工具附上一段说明**，这些定义随每一轮请求一起发出去。即使你只是问句简单的日常问题，还没开始正式对话，这份固定开销就已经付掉了，还顺带拖慢首字延迟。具体有多少个工具、占多少 Token，取决于客户端版本和你自己开了哪些扩展 —— 这里不写死一个数字。

### 2. ⏳ 速度与账单刺客：为什么聊着聊着突然变慢，Token 费用翻了 50 倍？
- **背后真相**：以 DeepSeek 官方为例，**命中缓存的 Token** 便宜得多：未命中 `$0.15 / 1M`，命中 `$0.003 / 1M`，**50 倍**（各家上游的价目不一样，这里只是拿它举例）。但 Claude 客户端每轮都在悄悄塞入动态当前时间、Git 快照、环境变量，甚至隔久了会偷偷从历史里剥掉思维链——**导致上游 Prompt Cache 被击穿**，原本命中缓存的那部分变成全量重新计算，又慢又贵。

### 3. 🤯 体验刺客：模型注意力涣散，甚至产生幻觉、乱调工具
- **背后真相**：把应用内浏览器、分屏、侧栏归档、设计稿同步等杂七杂八的工具全灌给模型，模型需要从几十上百个工具里挑挑拣拣，不仅处理变慢，还更容易出现幻觉或误调工具。

### 4. 🛠 门槛刺客：想接个便宜好用的第三方 API，配置起来掉层皮
- **背后真相**：官方 3P 推理面板、`~/.claude/settings.json`、`claude_desktop_config.json`……设置散落在 4 个深层配置文件里。改错一个字符客户端就闪退，遇到不兼容思维链（thinking）的模型更是直接报错趴窝。

## ⚡️ claude-tuner 怎么解决？

`claude-tuner` 是专为 **macOS 用户** 打造的 Claude 桌面端调控中枢。我们在本地架设一层轻量的透明优化网关，将所有分散的控制权收进**一个现代 Web 调控台**，为你提供：

| 痛点问题 | 原生 Claude 桌面端 | 搭配 claude-tuner 优化 |
| :--- | :--- | :--- |
| **首轮固定开销** | 每个可用工具的说明都随每轮请求发出 | **一键场景预设，按需移除冗余工具** |
| **缓存击穿率** | 频繁被时间戳、Git 状态打乱 | **前缀稳定化，让前缀尽量保持字节恒定** |
| **模型自由度** | 只能用官方昂贵模型 | **自由平替 DeepSeek、中转站、自建模型** |
| **配置管理** | 散落在 4 处深层配置文件中 | **精美现代 Web 调控台，一处修改全局生效** |

## 核心功能与亮点

### 1. ⚡️ 一键场景预设（3 秒开箱）
不用在 30 多个技术开关里迷茫，提供开箱即用的预设档位：
- **⚖️ 日常开发均衡档（推荐）**：保留代码、终端面板与网络搜索（若上游模型支持）；按需精简界面遥控与设计稿等冗余工具；开启前缀防击穿。兼顾全能与省钱。
- **⚡️ 纯代码极限档（极致省钱）**：精简所有非编码工具与网络搜索，首轮体积大幅缩减，Token 消耗压到极限，超低延迟且无额外联网计费！
- **🛠 原生全功能档**：完整保留所有官方原生几十上百个工具，仅做第三方模型平滑接入与前缀稳定化。
- **🎛 极客专家微调**：30+ 项细粒度开关，自由掌控每一字节。

### 2. 🛡 前缀字节恒定（防缓存击穿）
- 将动态日期、Git 状态快照、版本号标记等扰动逐项抹平。
- 客户端隔一段时间不用会从历史里剥掉思维链 —— DeepSeek 的缓存能活到约一天，思维链一没，前缀全变，那份还活着的缓存就白丢了。我们按会话记录原样补回去。
- 连通性探针本地秒回，不上云、不扣费。
- **每一条都是独立开关**，哪条不适合你的工作流，随手关掉即可。

> **不承诺命中率。** 能省多少取决于上游的缓存有效期和你自己的使用节奏，两头都不是这个项目能定的。它保证的只是「让前缀尽可能保持字节恒定」这个手段 —— 数字请大家在自己的账单里看。

![前缀稳定化](assets/5-rules.png)

### 3. ✂️ 工具与提示词精准解耦（实证防踩坑）
- 每一类工具都会在每轮请求里占用一份静态上下文，关掉一类省一类。
- **复合联动防反噬**：深入逆向验证发现，盲目关闭随附技能会导致客户端将 17KB 提示词内联进请求（反向膨胀！）。claude-tuner 独创复合开关，工具与提示词同步剥离，彻底杜绝负优化。
- **网页搜索按需配置**：控制客户端内置的联网搜索能力与配套工具定义。在纯代码编写或离线场景下勾选精简，可进一步降低上下文体积。

![工具精简](assets/2-tools.png)

- **核心工具严格受保护**：代码读写、终端执行、文件检索等核心工具（Bash / Read / Write / Edit / Glob / Grep 等）设为绝对受保护白名单，任何精简操作都不会误伤编程核心能力。

### 4. 🔌 自由接入任意模型（Anthropic 协议）
- DeepSeek 官方（`/anthropic`）、OpenCode、各大官方模型中转站、自建反向代理，填个 Key 一键即用。
- 一键拉取服务商支持的全部模型，并提供**真机连通性逐个测试**，通不通、耗时多少、返回什么一目了然。
- 客户端选择器直接读取你的映射配置：配几项，界面上就只显示几项，告别冗杂干扰。

## 安装与快速开始

### 一条命令安装

```bash
curl -fsSL https://raw.githubusercontent.com/ls-open/claude-tuner/main/install.sh | bash
```

**你只需要一个 API Key**（例如 DeepSeek 官方或中转站 Key）：

1. 运行安装命令，脚本会引导你输入 Key（也可以直接回车跳过，稍后在网页里填）。
2. 浏览器自动打开配置台，选择服务商、填入 Key，点击测试连接。
3. 点击右上角「保存更改」，然后**完全退出 Claude 再重新打开**（菜单里的「退出」，不是关闭窗口）。

> 浏览器没自动打开时，访问 **<http://127.0.0.1:8789/>** 即可 —— 浏览器会在第一次打开后记录访问授权，无需反复查找链接。

### 国内网络连不上 GitHub 时

安装脚本内置多重备用通道。若全不通：
- **下载 zip 安装**：在仓库点击 `Code → Download ZIP`，解压后在目录中执行 `bash install.sh`。
- **AI 助手辅助**：将此指令发给你的 AI 编程助手：“请帮我克隆 https://github.com/ls-open/claude-tuner 并执行 bash install.sh”。

### 验证是否生效

在 Claude 中随便发一条消息测试，然后查看网关日志：

```bash
tail -5 ~/.claude-tuner/logs/gateway.log
```

看到 `"event": "upstream_ok"` 即代表链路完全通畅！

| 标记 | 含义 | 涵盖范围 |

| **立即生效** | 网关配置，实时热加载 | 前缀稳定化、工具精简 |

## 常见问题 FAQ

**Q: 我直接在 Claude 桌面端登录我的官方网页账号（Pro / Team），能用这个吗？**  
A: **不能**。官方网页端账号登录走的是内部闭源认证链路，无法自定义上游和中转，且强制绑定官方全套固定配置。本项目专为通过 **API Key（3P 开发者模式）** 驱动 Claude 桌面端的场景设计。

**Q: 支持 OpenAI 格式的接口地址吗？**  
A: **不支持**。本项目是专注参数调优、防缓存击穿与工具调优的网关，**不做跨协议格式转换**。上游接口必须原生支持 **Anthropic Messages 协议**（例如 DeepSeek 官方需填带有 `/anthropic` 的端点，或中转站提供的 Claude 兼容端点）。填入纯 OpenAI 协议的 `/v1/chat/completions` 会报错。

**Q: 关掉那么多工具，会影响我日常让 Claude 写代码、读写文件吗？**  
A: **绝对不会**。核心文件操作（Read、Write、Edit、Glob、Grep）、终端命令（Bash）以及核心 Agent 调度能力属于**受保护工具**，系统底层做了硬隔离，任何配置都不会剥除它们。我们提供可选精简的只有分屏、窗口遥控、设计稿同步等当前不需要的辅助工具。

**Q: 网络搜索功能到底开还是关？**  
A: 取决于你接入的上游模型与业务场景。如果你的上游模型自身支持联网搜索功能，关闭剥离即可正常使用（请注意部分模型厂商联网搜索会额外计费）；如果是纯代码编写、离线环境或不需要搜索，关闭搜索可节省上下文开销并避免意外计费。在预设中，「日常开发均衡档」默认保留搜索能力，「纯代码极限档」默认剥离。

**Q: 装完之后没生效？**  
A: 99% 是没有完全重启客户端。必须在 macOS 菜单栏点击「退出 Claude」再重新打开（只按红叉关窗口不算完全退出）。

**Q: 网关挂了或者进程退出了怎么办？**  
A: **没有「官方回退」这回事** —— 客户端的上游地址就指着本机网关，网关不在时它会连不上上游、直接报错。好在保活是自动的：客户端每次启动会话、以及你每提交一条消息之前，都会跑一次保活钩子，发现网关不在就立刻拉起来。所以多数情况下你重新发一条消息它就回来了；也可以随时在配置页一键重启网关。

**Q: 为什么 DeepSeek 官方建议设自动压缩，而你们建议关掉？**  
A: 先把话说明白：上下文填满时压缩一次，**压缩那一次会把已有缓存丢掉，之后重新建立** —— 而不是「历史被改坏了」（那是把正常行为说成缺陷）。所以它是个取舍：换到 1M 大窗口之后压缩本来就很少触发，而每次触发都要让你重新付一遍前缀的钱，我们倾向关掉；你要是经常把上下文跑满，留着更稳。

**Q: 为什么目前只支持 Mac？**  
A: 本项目深入依赖了 macOS 平台的桌面端配置文件路径、进程锁判定与 Unix 套接字生命周期管理。Windows 系统下的文件锁与进程行为差异较大，为了保证极致的稳定性和安全，首版专注于 macOS。
