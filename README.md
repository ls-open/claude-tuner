# claude-tuner

**你的 Claude，工具和上下文都由你定。**

用 Claude 接第三方模型（DeepSeek / OpenCode / 中转站 / 自建反代）时，客户端每轮都会把**一大堆你
用不上的东西**重复发给模型；只要其中变了一点，上游就得**从头重算** —— 又慢又贵。claude-tuner
把这些变化抹平、把没用的砍掉，让它接得上上一轮、命中便宜的缓存价：**同样的活，花更少的钱。**

> **目前仅支持 macOS**，Windows 暂未支持 —— 愿意协助适配的话，见[文末](#windows-适配)。

## 亮点

- **少花钱** —— 把每轮都在变的那几样（当天日期、仓库状态、版本号…）抹平，请求就对得上上一轮，
  上游按缓存价算，账单更小。
- **工具面由你定** —— 客户端带的那些用不上的工具（分屏、窗口遥控、界面管理…）按类关掉；写代码
  要用的读写 / 执行 / 检索锁死关不掉。
- **一个网页搞定上游** —— 填地址和 Key、一键拉模型列表、逐个测连通；客户端选择器直接读你的映射。
- **装得干净、退得干净** —— 一条命令、零第三方依赖；卸载一键收回，改动都有备份。

> **我们不重做客户端，只把「哪些生效」交给你。** 客户端本身是扎实的，网关只是在它和上游之间
> 加一层你能调的中间层：规则逐条可关，关掉就退回客户端原样。

## 它到底改了什么

客户端发来的请求，进网关、出去之前会过三步：

```mermaid
flowchart LR
    A["客户端发来的请求"] --> B["① 砍掉用不到的工具<br/>连解释它们的提示词一起删"]
    B --> C["② 抹平每轮都在变的内容"]
    C --> D["发给模型"]
```

### 工具面：不再每轮重发用不上的说明

客户端会把**每个工具**的说明一起发出去，不管这轮用不用得上 —— 开着的扩展越多，这份固定开销越大。
网关按功能拆成一组组开关：

- **关一类，省一类**；核心工具（读文件 / 写代码 / 跑命令 / 搜文件）锁死，任何配置都关不掉。
- **关掉工具会连它的说明段落一起删** —— 不然模型会被引到一个不存在的工具上，比不关更糟。
- **不在名单里的一律原样透传** —— 客户端升级后新增的工具默认保留。

### 缓存：让请求接得上上一轮

上游按**请求开头的内容**命中缓存。开头只要有变化，后面就得全部重算 —— 又慢又贵。客户端偏偏每轮
都在开头塞会变的东西，这一组把它们逐项抹平：

| 每轮会变（或被丢掉）的 | 网关怎么办 |
|---|---|
| 当天日期、代码仓库状态 | 抹平成固定值 |
| 版本号、剩余额度这类计数 | 直接删掉 |
| 历史里丢掉的思考过程 | 补回来 |
| 一批工具返回的顺序 | 固定成一致的顺序 |
| 连通性检查请求 | 本地秒回，不花你的钱 |

> **不承诺具体数字。** 能省多少取决于上游缓存的有效期和你的使用节奏，这两头都不是我们能定的 ——
> 它只负责「让请求接得上上一轮」，剩下看你的账单。

### 上游接入：一个网页

- DeepSeek 官方、OpenCode、各类中转站、自建反向代理，填个 Key 一键即用。
- 一键拉取服务商支持的模型列表，**真机逐个测连通**：通不通、耗时多少、返回什么，一目了然。
- 客户端模型选择器直接读你的映射：配几项就显示几项。

## 装之前先确认

- **🔑 一个 API Key**：桌面端切到 **3P / 开发者接入模式**，填一个 Key 就能用。官方 Key、第三方
  兼容模型（如 DeepSeek）、中转站、自建反代都行。
- **⚡️ 上游要会说 Anthropic 协议**：本项目**不做**格式转译，填 `/v1/chat/completions` 会报错；
  DeepSeek 这类填 `https://api.deepseek.com/anthropic`。
- **📥 先装好 Claude 桌面端**：[到官网下载](https://claude.com/product/claude-code) 并至少打开一次
  （客户端第一次启动会自建配置目录，见下面「安装」）。
- **🍎 只支持 macOS**（依赖 macOS 的配置路径、进程锁判定与套接字生命周期）。

## 安装

> **先做一件事：打开一次 Claude，进到界面，然后退出。**
> 刚从官网下载、还没启动过的客户端，它的配置目录还不存在。客户端第一次启动会自己建一遍，
> 先让它建完，我们再往上改 —— 顺序反了分不清谁盖谁。（安装脚本检测到这种情况也会提醒你。）

```bash
curl -fsSL https://raw.githubusercontent.com/ls-open/claude-tuner/main/install.sh | bash
```

1. 运行安装命令，脚本会引导你输入 Key（也可以回车跳过，稍后在网页里填）。
2. 浏览器自动打开配置台，选服务商、填 Key、点测试连接。
3. 点右上角「保存更改」，然后**完全退出 Claude 再重新打开**（菜单里的「退出」，不是关闭窗口）。

> 浏览器没自动打开时，直接访问 **<http://127.0.0.1:8789/>** —— 第一次打开后浏览器会记住授权，
> 不用反复找链接。

**网络连不上 GitHub 时**：安装脚本内置多重备用通道。若全不通，可在仓库 `Code → Download ZIP`，
解压后执行 `bash install.sh`。

**验证是否生效**：

```bash
tail -5 ~/.claude-tuner/logs/gateway.log
```

看到 `"event": "upstream_ok"` 即代表链路通畅。

## 配置台

访问 **<http://127.0.0.1:8789/>** 进入调控台。所有开关改了都**即改即生效，可随时退回客户端原样**。

| 分组 | 内容 |
|---|---|
| 快速上手 | ⚡️ 场景预设 · 🔌 接上模型 · 🔀 模型映射 |
| 核心调优 | 💾 上下文缓存 · 🛡️ 请求稳定化 · ✂️ 工具精简 · 🎛️ 客户端偏好 |
| 运维与状态 | 📈 用量统计 · ⚙️ 网关状态 · 📦 版本与更新 |

每个开关旁边都标注了**生效时机**：

| 标记 | 写入哪里 | 涵盖 |
|---|---|---|
| **立即生效** | 网关自己的配置 | 缓存优化、工具精简 |
| **新会话生效** | 客户端设置 / 3P 配置 | 缓存保留时长、输入联想、终端联动、随附技能与工作流、定时任务 |
| **需重启客户端** | 3P 配置 / 桌面偏好 | 模型映射、1M 窗口、界面标签页 |

> 有几项写在客户端**运行时会覆盖回去**的配置里 —— 这类开关在 Claude 正在运行时会被页面拦下，
> 提示你先完全退出客户端再改。

> 清理了 Cookie 或提示访问令牌时，运行这条拿带 Token 的访问链接：
> ```bash
> python3 ~/.claude/skills/claude-tuner/scripts/webui.py --url
> ```

### 用量统计

直接取上游返回的 `usage`，不搞估算：缓存命中率、命中 / 未命中的 Token 分类、工具精简平均每次
剥掉多少个定义。省了多少，看这里，别听宣传。

## 终端 Claude Code 联动

安装时默认已打通：终端里的 `claude` 命令行工具同样经本网关转发，共用同一套上游与规则。

```bash
claude -p "只回复两个字：成功"
```

要在终端单独用官方账号，在配置台关掉「终端 Claude Code 同样走本网关」。

## 常见问题

**Q：关掉那么多工具，会影响写代码、读写文件吗？**
A：**不会**。Read / Write / Edit / Glob / Grep / Bash 以及核心 Agent 调度都在受保护名单里，
任何配置都剥不掉。可精简的只有分屏、窗口遥控、设计稿同步这类辅助工具。

**Q：网络搜索到底开还是关？**
A：**WebSearch / WebFetch 是服务端工具** —— 客户端只把工具定义发出去，真正去搜、去抓的是**上游**。
所以工具定义一直都在，开不开的区别只是它占不占那份上下文；能不能真用起来取决于你的上游有没有
实现它。

**Q：装完之后没生效？**
A：绝大多数是没有完全重启客户端。必须在 macOS 菜单栏点「退出 Claude」再打开（只按红叉关窗口不算）。
少数选项是**新会话生效** —— 保存后开一个新的对话即可，不用重启。

**Q：网关挂了怎么办？**
A：客户端每次启动会话、你每提交一条消息之前都会跑一次保活钩子，发现网关不在就拉起来。所以多数
情况下你重发一条消息它就回来了；也可以在配置页一键重启网关。

**Q：为什么建议关掉自动压缩，而 DeepSeek 官方建议开？**
A：压缩那一次会把已有缓存丢掉、之后重新建立 —— 不是「历史被改坏了」，是个取舍。换到 1M 大窗口
之后压缩本来就很少触发，而每次触发都要把已有缓存丢掉重算一遍（等于重付一次钱），我们倾向关掉；
你常把上下文跑满，留着更稳。
