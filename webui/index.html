新手极速指南 欢迎使用 claude-tuner · 3 步接上你自己的模型
1
配置上游接口 选择服务商或填入 Anthropic Messages 协议端点（官方 API/中转/DeepSeek）
2
填 API Key 填入你的密钥，点击「测试连接」验证上游通畅
3
保存并重启 点区块标题上的「保存 N 项」，然后完全退出并重开 Claude 即可生效！
①

接上模型

必填

填入 Anthropic Messages 协议接口与 API Key。支持官方 API、各类兼容中转及第三方模型直连。

②

模型映射

左列为客户端选择器代号，右列为发给上游的真实模型名（区分大小写，同时作为客户端内的显示名称）。

支持在线拉取可用模型，或手动指定上游模型名。
Claude 代号上游模型名 1M
注：客户端选择器直接读取此表；1M 列仅控制客户端内部窗口计算（修改后需完全退出并重启 Claude）。
③

上下文缓存

Claude 官方设置

控制客户端缓存保留时长与历史压缩。延长至 1 小时可显著提高连续对话命中率；按需关闭自动压缩可避免前缀频繁重建失效。

④

请求稳定化

发往模型前的请求优化与前缀清洗通道，最大化命中 Prompt 缓存并消除误拒答。

⑤

工具精简

按需精简客户端注入的外围辅助工具，配套的系统提示词将自动同步清理，节省上下文并释放模型注意力。

⑥

客户端偏好

Claude 官方设置

控制 Claude 桌面端的各项原生偏好（Git 提交签名、终端联动、随附技能与定时任务）。

⑦
